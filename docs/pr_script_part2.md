# 视频文案 · 后半段（#38 起）

> 接 `pr_script_fixed.md`（#1–37，停在“二代动态参数映射到一代包络”）。
> 风格与前半段一致：**字幕**给画面，**口播**给 TTS（符号已转汉字、英文按字母读）。
> 时长是建议值（按口播念完 + 半秒留白估的），时间轴你自己对齐。

## 38｜查找：说清“检索什么、标出什么”

- **字幕**：查找：检索音符与参数属性，命中项直接标出来
- **口播**：查找，可以检索音符属性，也可以检索参数曲线；命中的那一项，会直接在缩略图上标出来。
- **建议时长**：9 秒

## 39｜查找：条件与范围

- **字幕**：条件：大于 / 小于 / 等于 / 包含；范围：片段 / 轨道 / 工程
- **口播**：条件是大于、小于、等于或者包含，范围可以选当前片段、整条轨道，或者整个工程。
- **建议时长**：10 秒

## 40｜谱面编辑：写回 ACE 音符

- **字幕**：谱面编辑：五线谱和简谱共用一套坐标，改完一键写回音符
- **口播**：谱面编辑里，五线谱和简谱共用一套坐标；音高、时值、歌词都能直接在谱面上改，改完一键写回 ACE 的音符。
- **建议时长**：12 秒

## 41｜谱面编辑：导出乐谱

- **字幕**：导出乐谱：音符可导出 MusicXML，或你自己的简谱记法
- **口播**：反过来也能导出：把音符导出成 MusicXML 交给别的软件，或者导出成简谱文本，方便对稿。
- **建议时长**：12 秒

## 42｜二维码：默认隐藏的一项

- **字幕**：二维码：默认隐藏，在设置里勾开
- **口播**：二维码是默认隐藏的功能，需要在设置里勾开，主面板才会出现这颗红色按钮。
- **建议时长**：9 秒

## 43｜二维码：怎么摆才扫得出来

- **字幕**：按基准音摆方块，每行错开一个 tick，避免同一起点相撞
- **口播**：它把文本编成方块摆进音符轨：以基准音为起点往上排，每行错开一个 tick，避免同一时间点上的音符互相撞掉。
- **建议时长**：12 秒

## 44｜和声：默认不动原音高

- **字幕**：和声：复制一条轨写和声，原轨音高不动
- **口播**：和声面板默认不改原音高：它复制一条轨，把和声写在新轨上，原来的轨一个音都不动。
- **建议时长**：10 秒

## 45｜和声：整轨多片段，落点可拖

- **字幕**：范围可选整条轨；新轨位置直接拖
- **口播**：范围可以选整条轨道的所有片段；新轨放在哪一条，直接在缩略图上拖就行。先预览，再执行。
- **建议时长**：11 秒

## 46｜撤回这一批

- **字幕**：撤回这一批：一次退回本次全部写入
- **口播**：所有写操作都可以撤回。顶栏这颗“撤回这一批”，能一次把刚才那一批改动全部退回来。
- **建议时长**：9 秒

## 47｜快捷键

- **字幕**：每个功能都能绑系统级快捷键
- **口播**：每个功能都可以绑快捷键，点格子、按键、保存，就是系统级的，在 ACE 里也生效。
- **建议时长**：9 秒

## 48｜设置：一份配置管两边

- **字幕**：拖动排序、取消勾选即隐藏（快捷键仍有效）
- **口播**：设置页同时管侧栏和主面板：拖一下改顺序，取消勾选就是隐藏，但快捷键照样能用。
- **建议时长**：9 秒

## 49｜收尾

- **字幕**：单文件 · 静默启动 · 所有写入可撤回
- **口播**：ACETool，贴在 ACE 边上，双击就能跑；改歌词、搬参数、复制曲线，都变成一次点击。做错了，撤回这一批就好。
- **建议时长**：12 秒
