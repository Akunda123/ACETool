**首选 `idx_voice05_male_24k.wav`**：真人男声、语速稳、8.4 秒（在 5–15 秒窗口内），最适合“工具解说”这种口吻。

## 在 IndexTTS 里怎么用

1. 打开你的 `启动新版.bat` → 上传参考音频（上面任选一个）；
2. **参考文本**：可以留空（zero-shot 只要音色）；填的话就填该示例的原文（见上表最后一列），**别填你的新稿**；
3. 合成文本填你要念的稿子，例如：
   ```
   你看啊，这个工具，其实就贴在 ACE 边上。双击就能跑，不弹黑框，也不抢焦点。
   ```
