# ACETool 视频演示稿（口播 + 分镜）

> 用途：8 分钟左右的演示视频，覆盖 **初次使用 → 设置 → 功能展示**。
> 录屏环境：Windows 11 + ACE Studio 2.x（带 `acestudio-cli`）。ACETool 是单文件 exe，无安装包。
> 提示：全程用 **ACE 里的一条真实轨（含 2 个以上片段、已有歌词）** 当素材，演示才有说服力。

## 附录 C：常见坑（录进片子可以当“避坑提示”）

- **ACE 没开**：所有工具都会报“读不到”，侧栏也不出现——先开 ACE。
- **子窗口报 `Failed to fetch`**：那是 exe 重启换了端口；现在端口已固定，刷新页面即可。
- **改工程文件的工具**：片段之后命令行不能编辑、ACE 重开后会显示 `dirty`，属正常——保存即可。
- **撤销**：ACE 每个动词一条撤销记录；批量写会压很多条，用「撤回这一批」一次退。
